# بیرون (Beeroon) — نسخه اول (MVP)

دایرکتوری کسب‌وکارهای محلی، ساخته‌شده با Next.js + Tailwind + Supabase.
همه‌چیز روی سرویس‌های **رایگان** قابل اجراست: Vercel (هاست) + Supabase (دیتابیس رایگان تا ۵۰۰ مگابایت).

## این نسخه چی داره

- صفحه اصلی با دسته‌بندی و زیردسته‌بندی
- کارت کسب‌وکار با دکمه مستقیم تماس / واتساپ / اینستاگرام / تلگرام / نقشه
- فرم عمومی «ثبت کسب‌وکار» (می‌ره تو صف تایید مدیر)
- فرم جداگانه ثبت آنلاین‌شاپ با سایت، نوع فروش، ارسال، پرداخت و دسته تخصصی
- اطلاعات اختصاصی آنلاین‌شاپ در جدول مستقل `online_shop_details` نگهداری می‌شود
- پنل مدیریت ساده: ورود، تایید/رد/حذف/ویرایش/افزودن کسب‌وکار
- حالت شب و روز، طراحی راست‌به‌چپ کامل، فونت وزیرمتن
- بدون دیتابیس هم اجرا می‌شه (داده نمونه داخلی) تا سریع تستش کنی

## چیزهایی که *خودم* اضافه کردم چون لازم بود (و ازت نپرسیدم چون گفتی خودم تصمیم بگیرم)

- Supabase به‌جای یک دیتابیس اختصاصی، چون رایگان، بدون سرور جدا، و با Vercel عالی جفت می‌شه.
- ورود مدیر با Supabase Auth (ایمیل/رمز) به‌جای ساختن سیستم لاگین دستی — امن‌تر و صفر هزینه.
- حالت Demo: اگه هنوز Supabase رو وصل نکردی، سایت با داده نمونه بالا میاد تا چیزی خراب دیده نشه.
- رتبه‌بندی تصادفی نتایج (نه بر اساس پرداخت) — دقیقاً طبق اصل «دیده‌شدن برابر» تو پلن.

## چیزهایی که *نساختم* و باید بدونی

- درگاه پرداخت آنلاین برای اشتراک کسب‌وکارها (فاز دوم طبق خودِ پلن — نیاز به مجوز درگاه ایرانی مثل زرین‌پال داره که نیاز به اطلاعات کسب‌وکار رسمی توئه)
- اپ اندروید بومی (فاز اول با PWA پوشش داده می‌شه — همین سایت روی گوشی «Add to Home Screen» می‌شه)
- نقشه تعاملی کامل (فعلاً هر کارت لینک به گوگل‌مپس می‌ده؛ افزودن نقشه داخل صفحه با Leaflet/OpenStreetMap رایگانه و می‌تونم بعداً اضافه کنم)

## راه‌اندازی رایگان (۱۵ دقیقه)

### ۱. Supabase (دیتابیس رایگان)
1. تو [supabase.com](https://supabase.com) یک پروژه رایگان بساز.
2. برو **SQL Editor** → فایل `supabase/schema.sql` رو کپی/پیست کن و اجرا کن (جدول‌ها و داده نمونه ساخته می‌شن).
3. برو **Authentication → Users** → یک کاربر با ایمیل و رمز خودت بساز (این همون لاگین پنل مدیریتته).
4. برو **Project Settings → API** → مقادیر `Project URL` و `anon public key` رو کپی کن.

### ۲. اجرای محلی (اختیاری، برای تست)
```bash
cp .env.example .env.local
# مقادیر Supabase رو داخلش بذار
npm install
npm run dev
```

### ۳. دیپلوی روی Vercel (رایگان)
1. این پوشه رو به یک ریپازیتوری GitHub پوش کن.
2. تو [vercel.com](https://vercel.com) وارد شو → **Add New Project** → ریپازیتوری رو انتخاب کن.
3. تو تنظیمات پروژه، دو متغیر محیطی رو اضافه کن:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
4. Deploy بزن. آدرس رایگان `xxx.vercel.app` می‌گیری؛ بعداً می‌تونی دامنه `beeroon.ir` رو روش وصل کنی.

### ۴. ورود به پنل مدیریت
برو به `/admin` و با همون ایمیل/رمزی که تو Supabase ساختی وارد شو.

## یک نکته کوچیک

فایل `public/manifest.json` به دو آیکون (`icon-192.png` و `icon-512.png`) اشاره می‌کنه که هنوز داخل پروژه نیستن — هر لوگویی که برای بیرون طراحی کردی رو با همین اسم‌ها تو پوشه `public` بذار.

## نکته درباره مقیاس «همه‌ی شهرها»

طبق پلن، معماری از اول چندشهریه: هر کسب‌وکار یک `city_id` داره. فعلاً همه‌چیز رو `mashhad` فیکس کردم که فاز اول ساده بمونه؛ وقتی خواستی شهر دوم رو باز کنی، کافیه یک ردیف تو جدول `cities` اضافه کنی و یک سلکتور شهر به هدر اضافه کنم.
